## Что это такое

Chart Grabber — плагин OpenCPN, который скачивает карты для работы без интернета. Вы выбираете район (то, что сейчас на экране, нарисованный прямоугольник или полосу вдоль маршрута), источник карты и подробность; Chart Grabber CLI скачивает всё в фоне. Готовая карта добавляется в OpenCPN как карта MBTiles.

**Это не официальные карты. Не используйте их как единственное средство навигации. Соблюдайте условия использования каждого источника карт.**

## Какие задачи решает

- **Плагин и CLI вместе.** Раньше яхтсмены обычно скачивали тайлы через SAS.Planet или Mobile Atlas Creator (MOBAC), иногда обрабатывали их в QGIS, переводили в формат, который читает OpenCPN (MBTiles или KAP), и добавляли папку в OpenCPN. Chart Grabber CLI — независимый порт SAS.Planet ([sasgis/sas.planet.src](https://github.com/sasgis/sas.planet.src)) на C++ и Qt. Это не официальный проект SAS.Planet. Спасибо авторам SAS.Planet. Как и SAS.Planet, он распространяется под GPL-3.0-or-later. Chart Grabber не связан с MOBAC и QGIS. Теперь это одно окно внутри OpenCPN, а карта появляется в списке карт OpenCPN. Докачка, обновление и свежая погода тоже на месте.
- **Плагин** — это сторона OpenCPN: район (текущий вид, нарисованный на карте или вдоль маршрута), оценка объёма до скачивания, **My charts** (мои карты) и настройки.
- **Chart Grabber CLI** — отдельная программа командной строки, которая скачивает тайлы и пишет MBTiles без OpenCPN. Её могут использовать скрипты, другие картплоттеры, сервер или Raspberry Pi без OpenCPN, например чтобы обновлять погодные карты по расписанию (cron). См. [документацию Chart Grabber CLI](#документация-chart-grabber-cli).

## Установка

Нужны OpenCPN 5.10.2 или новее и Chart Grabber CLI 2026.10.9 или новее.

1. **Выберите архив** для своей системы (подробности — в файле COMPAT.md выпуска):

   | Система | `chartgrabber_pi-2026.10.4-` ... |
   |---|---|
   | Debian 13 x86-64 | `debian-x86_64-13-x86_64.tar.gz` |
   | Debian 13 arm64, Raspberry Pi OS trixie 64-bit | `debian-arm64-13-arm64.tar.gz` |
   | Debian 12, Ubuntu 24.04, Mint 22 (x86-64) | `debian-x86_64-12-x86_64.tar.gz` |
   | Ubuntu 24.04 arm64 | `ubuntu-arm64-24.04-arm64.tar.gz` |
   | Ubuntu 26.04 x86-64 / arm64 | `ubuntu-x86_64-26.04-x86_64.tar.gz` / `ubuntu-arm64-26.04-arm64.tar.gz` |
   | Arch / CachyOS | `arch-x86_64-rolling-x86_64.tar.gz` / `cachyos-x86_64-rolling-x86_64.tar.gz` |
   | Windows 10 и новее | `windows-x86.tar.gz` |

   Сборки для Raspberry Pi OS bookworm (Debian 12 arm64) и Ubuntu 22.04 нет.
2. **Импорт**: OpenCPN, Options (параметры), Plugins (плагины), **Import plugin...** (импортировать плагин), выберите архив, включите Chart Grabber. Для обновления импортируйте новый архив поверх старого.
   В OpenCPN 5.10.2 (пакеты Debian 12 и 13) кнопки Chart Grabber на панели инструментов может не быть, пока вы не закроете Options кнопкой **OK** или не перезапустите OpenCPN; до тех пор пользуйтесь меню правой кнопки **Chart Grabber: new chart of this view...**.
3. **Установите пакет Chart Grabber CLI**, например `sudo apt install ./chart-grabber-cli_2026.10.10_amd64.deb`. Arch и CachyOS: положите `chart-grabber-cli` в PATH или укажите его в [настройках](#справочник-настроек).
4. **Windows**: CLI поставляется отдельным 64-битным zip-архивом. Распакуйте его; плагин ищет `chart-grabber-cli.exe` в таком порядке: программа, указанная в настройках, папка `cli` в папке данных плагина, `Program Files\Chart Grabber CLI\`, затем PATH.
5. **Ubuntu 24.04**: её собственный OpenCPN (5.8.4) слишком старый; установите OpenCPN из PPA OpenCPN (`ppa:opencpn/opencpn`).

Debian 12: `sudo apt install -t bookworm-backports opencpn`.

## Первая карта за 2 минуты

1. Переместите карту на нужный район.
2. Нажмите кнопку **Chart Grabber** на панели инструментов или щёлкните по карте правой кнопкой: **Chart Grabber: new chart of this view...** (новая карта этого вида). Откроется страница **New chart** (новая карта) с выбранным **Current view** (текущий вид).
3. Выберите источник в **Chart** (карта); **More sources...** (другие источники) показывает их все.
4. Оценка появится сама: "About ... tiles, ... to download, ... on disk (... free)" (около ... тайлов, ... скачать, ... на диске (... свободно)).
5. Нажмите **Download** (скачать). Ход скачивания показывает полоска.
6. При "Chart added" (карта добавлена) нажмите **Show** (показать). Если карту не видно, щёлкните по ней в панели карт внизу. Для карт MBTiles нужен OpenGL (Options > Display > Advanced).

## Повседневная работа

- **Draw on chart** (нарисовать на карте): протяните прямоугольник или коснитесь двух углов. Правая кнопка или **Cancel** (отмена) — прекратить.
- **Along route** (вдоль маршрута): выберите маршрут и **Corridor width** (ширина полосы) — от 0.5 до 20 NM, по умолчанию 2.0.
- **Detail** (подробность): уровни **Passage** (переход) и **Coastal** (прибрежное плавание) включены по умолчанию, **Approach** (подход), **Harbour** (гавань, только для небольших районов), у каждого свой масштаб. Оценка показывает, сколько добавит ещё один уровень. Точные пределы: **Advanced** (дополнительно), **Least detail** / **Most detail** (наименьшая / наибольшая подробность).
- **Seamarks on top (OpenSeaMap)** (навигационные знаки поверх) добавляет буи и огни поверх карты.
- **My charts** (мои карты) показывает ваши карты с подробностью, размером, датой и состоянием. **Show** показывает карту; **More...** (ещё) предлагает **Top up** (докачать), **Update...** (обновить), **Build from saved tiles** (собрать из сохранённых тайлов), **Delete** (удалить), **Show in folder** (показать в папке).
- **Stop** (стоп) сохраняет прогресс: "Stopped. Resume any time from My charts." (остановлено; продолжить можно в любой момент из My charts). **Resume** (продолжить) продолжает скачивание.
- **Update...** заново скачивает тайлы старше, чем **Today (all tiles)** (сегодня, все тайлы), **1 month** (1 месяц), **6 months** (6 месяцев) или **1 year** (1 год).


## Погода

- Отметьте **Weather on top** (погода поверх) и выберите слой (радар осадков, облачность, осадки). Он создаётся отдельной картой.
- Радар достаёт примерно на 80-130 NM от берега; далеко в море погоду показывают только спутниковые снимки.
- В My charts, **More...**, **Update to latest weather** (обновить до свежей погоды) берёт самый новый снимок и создаёт новую карту, названную по его времени.

## В море и на медленной связи

- **Без интернета**: готовым картам связь не нужна. **Build from saved tiles** заново собирает карту из тайлов, которые уже есть на диске.
- **Сохранённые тайлы** позволяют Top up и Resume скачивать только недостающее; в настройках **Clear...** (очистить) освобождает место.
- **Slow or paid by the MB** (медленная или помегабайтно оплачиваемая связь: мобильный интернет, спутник): одно соединение, без автоматических повторов и **Limit per download** (предел на одно скачивание, по умолчанию 100 MB): перед большим скачиванием плагин спросит, а идущее скачивание остановится на пределе ("Stopped at your data limit (100 MB). Resume to continue." — остановлено на вашем пределе трафика (100 MB); нажмите Resume, чтобы продолжить).
- **Повторы**: в обычном режиме при потере связи скачивание встаёт на паузу и повторяется 3 раза с интервалом 60 с ("No connection. Retry in 60 s (1 of 3)" — нет связи, повтор через 60 с (1 из 3)); затем "No connection. Download paused; your progress is saved." (нет связи; скачивание на паузе, прогресс сохранён).

## Свои источники

- 28 источников, которые идут с плагином: [Карты в комплекте](#карты-в-комплекте).
- Добавьте свои папки источников `.zmp` в `Charts/Chart sources` в домашней папке (в настройках **Chart sources** (источники карт), **Open folder** (открыть папку) создаёт её) или выберите другую папку через **Change...** (изменить). Они читаются после комплектных.
- Источники, которым нужен ключ, и Navionics в комплект не входят: положите папку источника туда и впишите свой ключ там, где в его файле стоит `KEY`.

## Неполадки

| Признак | Что делать |
|---|---|
| "Chart Grabber CLI was not found" (Chart Grabber CLI не найден) | Установите CLI (в Windows распакуйте zip) или укажите его в разделе Advanced настроек. |
| "Chart Grabber CLI ... is too old" (Chart Grabber CLI ... слишком старый) | Установите Chart Grabber CLI 2026.10.9 или новее. |
| Карта добавлена, но её не видно | Щёлкните по ней в панели карт; включите OpenGL (Options > Display > Advanced). |
| Источник серый в More sources или Seamarks on top недоступен | Из него нельзя сделать карту OpenCPN; текст рядом объясняет почему. |
| "Area too large for this detail" (район слишком велик для этой подробности) | Выберите район поменьше или меньшую подробность. |
| Нет кнопки Chart Grabber на панели инструментов | OpenCPN 5.10.2 добавляет её только при запуске или по **OK** в Options: нажмите OK или перезапустите OpenCPN. Пока что щёлкните по карте правой кнопкой: **Chart Grabber: new chart of this view...**. |
| Import plugin не принимает архив | Сверьтесь с [таблицей систем](#установка) и проверьте, что OpenCPN 5.10.2 или новее. |
